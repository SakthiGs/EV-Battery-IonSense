# Contributing to EV-Battery-IonSense

Thank you for your interest in contributing to EV-Battery-IonSense.

This repository curates public EV and lithium-ion battery datasets, related papers, and resources for battery health estimation, degradation modelling, anomaly detection, safety analytics, second-life assessment, and quantum-ready battery data discovery.

## How to contribute

You can contribute by suggesting:

- new public battery datasets
- corrected dataset links
- related papers
- metadata updates
- broken-link reports
- improved descriptions or categories

## Dataset entry format

When suggesting a new dataset, please include:

- dataset name
- dataset URL
- related paper or documentation
- battery chemistry, if known
- task type: SOH, SOC, RUL, anomaly, failure, second-life, etc.
- modality: BMS time-series, EIS, voltage relaxation, imaging, thermal, strain, magnetic, etc.
- access status: public, restricted, code-only, unavailable
- license, if known

## Important note

This repository does not host or redistribute third-party datasets. It only provides curated links and metadata. Please follow the citation, license, and usage terms of the original dataset providers.
