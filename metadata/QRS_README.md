# IonSense-QKG QRS artifact notes

This folder contains the quantum-readiness metadata used by the QC&DKM 2026 short-paper artifact.

## Files

- `qrs_schema.yaml` — QRS component definitions, default weights, and interpretation.
- `datasets_qkg_enriched.csv` — enriched seed metadata with component-level high/medium/low annotations.
- `datasets_qkg_ranked.csv` — deterministic weighted-QRS ranking generated by `scripts/compute_qrs.py`.
- `qrs_cross_method_agreement.csv` — cross-method rank agreement for additive, gated, continuous, and uniform variants.
- `qrs_sensitivity_grid.csv` — weight-sensitivity summary under Gaussian perturbations.
- `qrs_robustness_report.txt` — human-readable robustness summary.

## Interpretation

QRS is a transparent metadata-driven heuristic for NISQ workflow readiness. It is not an empirical claim of quantum advantage and does not mean that quantum models were trained on all datasets.

The primary weighted score is:

`QRS(D)=0.25F(D)+0.20S(D)+0.20M(D)+0.15L(D)+0.15P(D)+0.05A(D)`

where `P` is stored in the CSV as `preprocessing_burden` for compatibility, but is interpreted in the paper as preprocessing feasibility: high means the dataset is easier to prepare for quantum-ready input.
